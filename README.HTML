印表機設定搬家工具

用一份備份把 Windows 印表機佇列、驅動程式、連接埠、共用資訊與自訂紙張表單搬到另一台電腦。這份說明從首次啟動一路帶你完成匯出、移轉與匯入。

一、開始前先確認

先在舊電腦匯出備份，再把檔案帶到新電腦匯入。不要在新電腦先刪除印表機；匯入時同名佇列可能會更新。

1完整解壓縮
把 ZIP 解壓到資料夾，不要只從壓縮檔內直接執行單一檔案。
2保留同一資料夾
PrinterBackup.exe、PrinterBackup.ps1 和啟動檔需放在一起。
3準備管理員帳號
匯出、匯入及安裝 Windows 列印管理元件都需要管理員權限。
4保持網路連線
若電腦缺少 PrintBRM，Windows 可能會從 Windows Update 或企業功能來源下載元件。
Server 版本：Windows Server 2022 / 2025 請使用 Desktop Experience（桌面體驗）。Server Core 沒有此視窗程式所需的桌面環境。

二、啟動程式與自動安裝

  1. 在解壓後的資料夾雙擊 PrinterBackup.exe，或雙擊「一鍵啟動.cmd」。
  2. Windows 會在啟動時顯示 UAC 視窗。按「是」或輸入管理員帳號密碼，程式才會以系統管理員身分執行。
  3. 程式會檢查 PrintBRM 與 Print Spooler 狀態。若找不到 PrintBRM，會自動安裝 Windows 官方列印管理元件，完成後再開放匯出／匯入。

Windows 10 的 Print Management Console 選用功能自 2004 版起提供。若較舊 Windows 10 沒有此功能，請先更新 Windows，或依畫面錯誤使用適用於該版本的 Windows 元件來源。

管理員啟動：EXE 已內嵌 Windows 的 requireAdministrator 設定。雙擊時先出現 UAC，允許後才啟動；若按「否」或取消，Windows 會阻止程式啟動。

三、在舊電腦匯出

  1. 啟動工具並確認「PrintBRM：已找到」及「Print Spooler：Running」。
  2. 按「匯出備份」。
  3. 在存檔視窗選擇備份位置與檔名。預設檔名包含電腦名稱和時間，副檔名為 .printerExport。
  4. 按「儲存」，等待進度完成。印表機多、驅動程式大或網路磁碟速度較慢時，可能需要幾分鐘。
  5. 看到「作業完成」並在紀錄中出現「完成：檔案路徑」，代表匯出程序已結束。
建議：把備份存到本機資料夾，再複製到同步磁碟或 USB。匯出中不要關閉程式、關機或中斷磁碟。

四、把備份帶到新電腦

把整個 .printerExport 檔複製到新電腦可讀寫的位置。若透過網路或同步資料夾，先確認檔案已完整同步完成，再進行匯入。

五、在新電腦匯入還原

  1. 把免安裝工具資料夾解壓到新電腦，雙擊 EXE 或一鍵啟動檔，並允許 UAC。
  2. 若 PrintBRM 不存在，先等待 Windows 自動下載／安裝完成。下載來源受網路或組織原則限制時，程式會顯示錯誤。
  3. 按「匯入還原」，選擇從舊電腦複製來的 .printerExport 檔。
  4. 閱讀確認視窗。匯入會加入備份項目；目的電腦已有同名佇列時，設定可能會被更新。確認後按「是」。
  5. 等待匯入結束，閱讀紀錄並確認完成訊息。過程中不要關閉程式或停止 Print Spooler。
注意：匯入的是備份裡的多個佇列和驅動程式，不是單一印表機。若新電腦已有相同名稱的印表機，可能會更新其設定。

六、匯入後逐項檢查

PrintBRM 結束碼成功不代表每個廠牌專屬選項都一定完全相同。建議到 Windows「設定 → 藍牙與裝置 → 印表機與掃描器」或「列印管理」逐項檢查：

  • 印表機名稱與佇列是否都出現
  • 驅動程式名稱、版本和架構是否合適
  • 連接埠、IP 位址或 USB 連線是否正確
  • 共用名稱、共用狀態和權限是否符合需要
  • 紙張尺寸、自訂表單、紙匣與雙面設定
  • 預設印表機與預設紙張方向
  • 每台實體印表機是否在線上
  • 列印一張測試頁確認輸出

若某一台印表機未恢復或設定不同，開啟事件檢視器查看 PrintBRM 管理記錄：Applications and Services Logs / Microsoft / PrintBRM / Admin。也可在程式紀錄中查看 PrintBRM 輸出。

七、常見問題與處理方式

雙擊後沒有畫面，或 UAC 被取消

請重新雙擊 PrinterBackup.exe 或「一鍵啟動.cmd」，在 UAC 視窗按「是」。若是標準使用者帳號，需輸入管理員帳號密碼。沒有管理員核准時，Windows 不會允許安裝或匯入驅動程式。

自動安裝 Print Management 失敗

請確認電腦能連到 Windows Update 或企業設定的 Features on Demand 來源。公司網域的 WSUS／群組原則可能封鎖選用功能下載。重新啟動工具會再嘗試一次；若仍失敗，請把程式顯示的完整錯誤交給系統管理員。

提示 Print Spooler 未執行

在 Windows「服務」中啟動「Print Spooler／列印多工緩衝處理器」，再重新執行匯出或匯入。不要在 PrintBRM 工作進行中停止此服務。

匯出或匯入顯示錯誤碼／部分印表機跳過

先保留錯誤文字和 `.printerExport` 備份，再查看事件檢視器的 PrintBRM/Admin 記錄。確認磁碟可寫入、備份檔完整、目的電腦有足夠空間，以及驅動程式支援目的 Windows 架構。不要反覆匯入不明或損壞的備份。

新電腦的印表機已出現，但無法列印

檢查印表機 IP／連接埠、網路連線、USB 線、驅動程式與印表機本身狀態。跨不同 Windows 版本或處理器架構時，可能需要先安裝新電腦適用的廠牌驅動程式，並在印表機內容中重新指定機型選項。

匯出成功，但紀錄中的中文亂碼

請使用最新版工具。新版會依輸出內容判斷 UTF-8 或 Windows OEM 編碼；若仍出現亂碼，請保留 `.printerExport` 檔，因紀錄文字亂碼不一定代表備份內容損壞，並回報完整紀錄。

八、備份內容與限制

本工具呼叫 Windows PrintBRM，將目前電腦可搬移的印表機伺服器設定打包成 `.printerExport`。涵蓋支援的佇列、驅動程式、連接埠、共用資訊、伺服器列印設定與自訂紙張表單。

不包含：廠商掃描／傳真工具、帳號憑證、印表機面板或雲端服務設定、應用程式內的個人列印偏好。USB 設備在新電腦可能需重新接線或指定連接埠。

來源與目的電腦建議使用相同處理器架構。Windows Server 請使用桌面體驗。程式會從 Windows 元件來源安裝管理工具，不會從第三方網站下載 Windows 系統檔。
